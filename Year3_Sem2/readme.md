# Year 3 Semester 2

## About This Semester

Year 3 Semester 2 was a more applied and data-focused semester. The courses in this folder moved from general technical concepts toward practical work in business intelligence, high performance data processing, and special topics in data engineering. The semester required more independent learning, more project coordination, and a stronger connection between tools, data, and real-world use cases.

## Courses and Reflections

- [Business Intelligence](BUSINESS_INTELLIGENCE/readme.md) - learned how to prepare, transform, and present data for decision making through workflow-based BI tasks and an industry perspective report.
- [High Performance Data Processing](HIGH_PERFORMANCE_DATA_PROCESSING/readme.md) - learned how to process large datasets efficiently and compare scalable tools such as Pandas, Dask, and Polars.
- [Special Topic in Data Engineering](SPECIAL_TOPIC_IN_DATA_ENGINEERING/readme.md) - explored modern data engineering topics such as cloud pipelines, Spark, AI-assisted workflows, and business intelligence solutions.

## Overall Reflection

This semester helped me see how data engineering and analytics are used in more practical settings. It improved my understanding of how to handle data at different scales, how to turn data into useful insights, and how to connect technical tools with business needs.

Overall, Year 3 Semester 2 strengthened my interest in data engineering because it showed how cloud platforms, big data processing, and BI workflows can work together in real projects.
