
# 🏬 BI Project Reflection: Retail Strategy - The Impact of GDP and Urbanization on European Sales

## Project Overview

This project focused on developing a Business Intelligence solution to analyse how **GDP** and **urbanization** affect retail sales performance across European countries.

The project combined internal sales data with external socio-economic datasets to understand customer shopping behaviour across **online** and **offline** sales channels. The final goal was to support better retail strategy decisions by identifying which countries may be more suitable for digital expansion or physical retail investment.

## Tools Used

- **Alteryx Designer** – ETL workflow, data cleaning, transformation, and data integration
- **Microsoft Power BI** – dashboard visualization and business reporting
- **CSV / Excel datasets** – structured data sources for analysis

## Datasets Used

The project used three main datasets:

1. **Europe Sales Records**  
   Used to analyse sales revenue, profit, product categories, and sales channels.

2. **Global GDP Explorer 2025**  
   Used to understand each country’s economic strength through GDP and GDP per capita.

3. **Countries of the World 2023**  
   Used to analyse demographic indicators such as urban population and population size.

## What I Gained

Through this project, I learned how BI can be used to connect business data with external economic and demographic factors. Instead of only looking at sales performance, this project helped me understand how GDP and urbanization can provide deeper context for business strategy.

I also gained practical experience in building an ETL workflow using Alteryx Designer. The workflow involved cleaning each dataset, correcting data types, removing duplicates, standardizing country names, converting dates, handling missing values, and joining all datasets into one master dataset.

## BI Workflow Experience

The project workflow was divided into several parts:

- GDP dataset cleaning and formatting
- Europe sales data cleaning and KPI calculation
- Urbanization dataset cleaning and missing value handling
- Combined dataset creation using country as the join key
- Final output preparation for Power BI dashboard development

Some important calculated fields were also created, such as **Profit Margin Percentage**, **Urban Population Percentage**, **Profit per Urban Resident**, **Channel Preference**, and **GDP Tier**.

## Reflection

This project helped me understand that a good dashboard depends on a strong data preparation process. If the data is messy, duplicated, or inconsistent, the final dashboard may give misleading insights.

The project also showed me that BI is not just about using tools. It requires understanding the business problem, choosing the right datasets, preparing the data correctly, and presenting insights in a way that supports decision-making.

## Suggested Improvements

This project could be improved by using more recent and larger sales datasets. Predictive analytics could also be added to forecast future sales performance or recommend suitable countries for online and offline retail expansion.

## Overall Learning

Overall, this project was meaningful because it allowed me to apply the full BI process from data preparation to dashboard development. It strengthened my understanding of ETL workflows, data integration, KPI creation, and business-focused dashboard design.
