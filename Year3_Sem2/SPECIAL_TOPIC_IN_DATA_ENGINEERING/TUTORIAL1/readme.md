## ☁️ Reflection: Tutorial 1 - Microsoft Azure Data Pipeline

Through this tutorial, I gained a better understanding of how Microsoft Azure can be used to build an end-to-end data engineering pipeline. The tutorial showed how data can be moved from an on-premises SQL Server into the cloud, stored in different layers, transformed, and finally visualized using Power BI.

### 💡 What I Gained

I learned how different Azure services work together in a modern data pipeline. **Azure Data Factory** was used for data ingestion, **Azure Data Lake Storage Gen2** was used to store data in Bronze, Silver, and Gold layers, **Azure Databricks** was used for data transformation, and **Azure Synapse Analytics** was used to prepare data for reporting.

This tutorial also helped me understand the importance of the **Medallion Architecture**. By separating raw, cleaned, and business-ready data into different layers, the pipeline becomes more organized, traceable, and easier to maintain.

### 🔧 Suggested Improvements

The pipeline could be improved by adding more data validation rules and automated alerts when the pipeline fails. Besides that, more advanced Power BI dashboards with interactive filters and KPI summaries could be added to help users explore business insights more effectively.

### 🌟 Overall Reflection

Overall, this tutorial was useful because it showed me how cloud-based data engineering works in a real-world scenario. It helped me connect concepts such as data ingestion, data storage, transformation, security, automation, and visualization into one complete workflow.
