# 📘 Special Topic in Data Engineering

This folder contains coursework, tutorials, projects, and reflections completed for **SECP3843 Special Topic in Data Engineering**. The subject focuses on modern data engineering concepts, including cloud data pipelines, big data processing, artificial intelligence, data quality automation, and business intelligence solutions.

---

## 📌 Course Summary

Throughout this course, several practical data engineering topics were explored through tutorials and projects. The learning activities covered the use of **Microsoft Azure**, **Apache Spark**, **AI algorithms**, **AI-assisted data pipelines**, and **Business Intelligence dashboard design**. These topics helped me understand how data can be collected, processed, transformed, stored, analyzed, and visualized to support decision-making.

The course also introduced real-world data engineering practices such as **ETL/ELT pipelines**, **Medallion Architecture**, **cloud storage**, **data warehouse design**, **star schema modelling**, **large-scale data processing**, and **dashboard development**. Through the assignments, I was able to connect theoretical concepts with practical tools and workflows used in industry.

---

## 💡 What I Gained

Through this subject, I gained stronger knowledge of how data engineering supports business and technical decision-making. I learned that a good data pipeline is not only about moving data from one place to another, but also about ensuring that the data is clean, reliable, well-structured, and ready for analysis.

I also gained hands-on exposure to different tools and technologies such as **Azure Data Factory**, **Azure Data Lake Storage Gen2**, **Azure Databricks**, **Azure Synapse Analytics**, **Power BI**, **Apache Spark**, **PySpark**, **PostgreSQL**, **Metabase**, **TensorFlow**, **Keras**, **Airflow**, and **AI agents**. These tools helped me understand how different parts of the data engineering ecosystem work together.

Another important lesson I gained is the importance of data quality. Several tutorials showed that raw data often contains missing values, duplicates, invalid formats, and inconsistencies. Because of this, data cleaning, validation, transformation, and monitoring are important steps before data can be used for reporting or machine learning.

---

## 🧠 Reflection

This course was meaningful because it gave me a broader view of the data engineering field. Before this, I mainly understood data engineering as database management or basic data processing. However, through this subject, I realized that data engineering involves many connected areas, including cloud computing, big data, AI, automation, data modelling, and business intelligence.

The tutorials helped me build technical confidence step by step. The Microsoft Azure tutorial introduced me to cloud-based pipeline architecture. The Apache Spark tutorial helped me understand how large datasets can be processed efficiently. The AI algorithm tutorial introduced me to CNN-based image classification. The AI-assisted pipeline tutorial showed how AI agents can support data quality checking, while the BI article tutorial helped me understand how dashboards can support management decisions.

The Project PPG assignment was especially useful because it combined many data engineering concepts into one practical case. It allowed me to apply cloud pipeline design, Medallion Architecture, data transformation, and Power BI dashboard development in a business-related scenario.

---

## 🔧 Suggested Improvements

This course could be improved by including more guided hands-on sessions for complex tools such as Azure, Apache Spark, and Airflow. Since some tools require setup, configuration, and troubleshooting, step-by-step lab guidance would help students understand the workflow more smoothly.

It would also be helpful if more real industry datasets were provided, so students can experience data engineering challenges closer to real working environments. More explanation on deployment, pipeline monitoring, error handling, and automation would also make the learning experience more complete.

---

## 🌟 Overall Reflection

Overall, this subject helped me understand the role of a data engineer more clearly. I learned that data engineers are responsible for building reliable pipelines, preparing high-quality data, designing suitable data models, and supporting analytics or machine learning processes.

This course strengthened my interest in **Data Engineering** because it showed how technical skills can be used to solve real business problems. It also helped me become more familiar with modern tools and workflows that are important for future internship and industry work.
