## 🤖 Reflection: Tutorial 3 - AI Algorithm

Through this tutorial, I gained a clearer understanding of how Artificial Intelligence can be applied in image classification. The tutorial focused on building a Convolutional Neural Network (CNN) model using Python to classify images from the CIFAR-10 dataset.

### 💡 What I Gained

I learned the basic concepts of **image classification** and how CNN works through layers such as convolutional layers, activation functions, pooling layers, fully connected layers, and output layers. This helped me understand how a model can automatically learn image features such as edges, shapes, textures, and patterns.

I also gained hands-on experience in using **TensorFlow**, **Keras**, **NumPy**, and **Matplotlib** to load datasets, preprocess images, build a CNN model, train it, and evaluate its performance. The tutorial also helped me understand evaluation metrics such as accuracy, loss, precision, recall, and F1-score.

### 🔧 Suggested Improvements

The model could be improved by applying stronger data augmentation, adding dropout layers, tuning hyperparameters, and increasing the model depth carefully to improve classification accuracy. More epochs and better training strategies could also help reduce overfitting and improve model generalization.

### 🌟 Overall Reflection

Overall, this tutorial was meaningful because it introduced me to deep learning in a practical way. It helped me understand that AI model development is not only about training a model, but also about preparing data, selecting the right architecture, evaluating performance, and improving the model based on its weaknesses.
