## 🧠 Reflection: Claude and AI-Assisted Data Pipeline

Through this tutorial, I gained a better understanding of how AI can support data engineering workflows. The tutorial focused on using an AI agent to perform dataset profiling, detect data quality issues, and generate a data quality report.

### 💡 What I Gained

I learned how AI-assisted data engineering can reduce manual work in data quality checking. Instead of writing fixed validation rules for every issue, the AI agent was able to analyze the dataset, identify missing values, duplicate records, invalid formats, unrealistic values, and generate recommendations.

This tutorial also helped me understand how AI agents can be integrated into a data pipeline. The workflow included dataset creation, AI agent prompt configuration, issue detection, report generation, data cleaning using pandas, and pipeline execution using Airflow.

### 🛠 Technical Experience

I gained practical exposure to **Airia AI Agent**, **Claude Haiku**, **Python**, **pandas**, **Apache Airflow**, and API integration. I also learned how prompt design affects the quality of AI-generated output, especially when asking the AI model to profile data or detect issues.

### 🔧 Suggested Improvements

The pipeline could be improved by adding stronger validation rules after the AI output to ensure the detected issues are accurate. More datasets with different formats could also be tested to evaluate whether the AI agent can handle more complex real-world data.

### 🌟 Overall Reflection

Overall, this tutorial was interesting because it showed how AI can become part of the data engineering process. It helped me see that future data pipelines may not only depend on manual scripts, but also use AI to assist with data profiling, anomaly detection, reporting, and documentation.
