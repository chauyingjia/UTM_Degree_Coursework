## 🏭 Reflection: Recoverable Assets & Inventory Risk Management Pipeline

Through this project, I gained a stronger understanding of how data engineering can be used to solve real business problems. I learned how an end-to-end data pipeline can transform raw operational data into meaningful insights for inventory risk management. This project also helped me understand the use of **Medallion Architecture**, where data is processed through **Bronze, Silver, and Gold layers** to improve data quality and prepare it for analysis.

### 💡 What I Gained

I learned how Microsoft Azure services can support the data engineering process. By using tools such as **Azure Data Factory**, **Azure Data Lake Storage Gen2**, **Azure Synapse Analytics**, and **Power BI**, I was able to understand how data ingestion, cleaning, transformation, storage, and visualization are connected in a real pipeline.

This project also improved my understanding of business intelligence. The Power BI dashboards made it easier to monitor inventory health, financial risk, expired materials, dead stock, and stockout risks. It showed me that a good dashboard is not only about visual design, but also about helping stakeholders make better decisions.

### 🔧 Suggested Improvements

The project could be improved by adding **real-time data updates**, **automated alert notifications**, and **predictive analytics** to forecast inventory risks earlier. The dashboard design could also be enhanced with more interactive filters, clearer KPI summaries, and better drill-down features for deeper analysis.

### 🌟 Overall Reflection

Overall, this project was meaningful because it allowed me to apply data engineering concepts in a practical industry-related case. It strengthened my skills in cloud data pipelines, data transformation, data modelling, and dashboard development. Most importantly, it helped me understand how data can support business decision-making and reduce manual effort in inventory risk management.
