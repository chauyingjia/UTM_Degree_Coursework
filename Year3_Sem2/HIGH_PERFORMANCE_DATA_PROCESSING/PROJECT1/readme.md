## 🕷️ Reflection on Project 1: JobStreet Web Crawler & High-Performance Processing Project

Through this project, I gained a stronger understanding of how high-performance data processing can be applied to a real-world data collection and processing pipeline. The project focused on building a pipeline to collect, clean, process, optimize, and evaluate job listing data from JobStreet Malaysia.

### 💡 What I Gained

I learned how a complete data pipeline works from the beginning to the end. The process started with web crawling, where job listing data was collected from JobStreet Malaysia. The raw data was then stored, cleaned, transformed, optimized, and evaluated using different processing frameworks.

This project helped me understand how raw online data can be converted into a structured and analysis-ready dataset. It also showed me the importance of data quality before performance optimization can be carried out.

### 🧹 Data Cleaning & Processing Experience

My part in the project focused on the data cleaning pipeline. I worked on removing duplicate records, handling missing values, standardizing text formats, cleaning location names, extracting salary values, and preparing the final cleaned dataset in CSV format.

Through this process, I learned that data cleaning is a very important stage because raw scraped data usually contains repeated records, inconsistent formats, missing values, and unstructured text. Without proper cleaning, the final analysis may become inaccurate or difficult to use.

### ⚡ Optimization & Performance Evaluation

The project also introduced different optimization approaches using **Pandas, Polars, and DuckDB**. These tools were used to compare execution time, memory usage, CPU usage, and throughput.

From the results, I learned that different tools have different strengths. Optimized Pandas can reduce memory usage through better data type handling, Polars can provide faster execution through lazy evaluation and parallel processing, while DuckDB is useful for SQL-based analytical processing.

### 🔧 Suggested Improvements

This project could be improved by testing the pipeline on a larger dataset and adding more advanced analytical tasks, such as job demand trend analysis, salary prediction, or skill extraction from job descriptions. The system could also be enhanced with automated scheduling, real-time crawling, and dashboard visualization.

### 🌟 Overall Reflection

Overall, this project was meaningful because it allowed me to apply high-performance data processing concepts in a practical project. It strengthened my understanding of web crawling, data cleaning, data transformation, optimization techniques, and performance evaluation. Most importantly, it showed me how data processing pipelines can be designed to turn raw web data into useful insights.
