
# ⚡ High Performance Data Processing Reflection

## 📘 Course Overview

This course focused on processing large datasets efficiently and comparing different approaches to improve performance. The work in this folder includes an academic writing paper, a big data assignment using the Netflix movie ratings dataset, AWS Academy online courses, and a group project related to high-performance data processing.

Through this course, I gained a better understanding of how large-scale data can be collected, processed, optimized, and evaluated using different high-performance data processing techniques. This course helped me explore both theoretical and practical aspects of data processing, including infrastructure comparison, big data handling strategies, web crawling, data cleaning, cloud computing concepts, and performance benchmarking.

---

## 📝 Assignment 1: AWS EC2 vs. On-Premises Servers Article

In this assignment, I wrote an academic article comparing **AWS EC2** and **on-premises servers** for large enterprises. The comparison focused on infrastructure choice, scalability, control, security, performance stability, and suitability for organizations that handle sensitive or critical data.

This assignment helped me understand that cloud infrastructure is useful for elastic and dynamic workloads, while on-premises infrastructure is still important for organizations that require stronger control, data sovereignty, and predictable performance.

---

## 📊 Assignment 2: Big Data Handling with Netflix Ratings Dataset

This assignment focused on analysing a large **Netflix movie ratings dataset** using different big data handling techniques. I explored how large datasets can be processed more efficiently by applying methods such as column selection, chunking, data type optimization, and scalable data processing libraries.

The comparison between **Pandas, Dask, and Polars** was especially useful because it showed the trade-offs between simplicity, speed, memory usage, and scalability. I learned that choosing the right tool is important when working with large datasets because different libraries perform better under different workloads.

---

## 🕷️ Project: JobStreet Web Crawler & High-Performance Processing Pipeline

For the course project, my group developed a high-performance data processing pipeline based on **JobStreet Malaysia job listing data**. The project involved collecting job data through web crawling, storing raw data, cleaning and transforming the dataset, applying optimization techniques, and evaluating the performance of different processing approaches.

The pipeline included several stages:

- Web crawling and data collection from JobStreet Malaysia
- Raw data storage in JSON format
- Data cleaning and transformation using Python and Pandas
- Duplicate removal, missing value handling, text standardization, and salary extraction
- Optimized processing using **Pandas, Polars, and DuckDB**
- Performance evaluation based on execution time, memory usage, CPU usage, and throughput

My main contribution was in the **data cleaning and preprocessing stage**, where raw scraped job data was transformed into a cleaner and more structured dataset. This helped me understand that data quality is very important before any optimization or analysis can be performed.

## 💡 Reflection

This course taught me that working with large data is not only about getting the correct result, but also about doing it efficiently. The project showed me how important it is to reduce memory usage, process data in smaller pieces, and choose the right tool for the workload.

The Netflix analysis was especially useful because it allowed me to compare Pandas, Dask, and Polars on the same task. That comparison helped me understand the trade-offs between simplicity, speed, and scalability. It also showed me how techniques such as selecting only needed columns, chunking data, and optimizing data types can make a big difference when datasets become large.

The JobStreet project also gave me practical experience in building a complete data processing pipeline. I learned that raw web data usually contains duplicates, missing values, inconsistent formats, and unstructured text. Because of this, proper data cleaning is necessary before the data can be used for analysis or performance testing.

The AWS Academy courses further supported my learning by helping me understand how cloud services can be used in modern data processing environments. They gave me a stronger foundation in cloud computing, which is important for handling scalable and flexible data workloads.

---

## 🌟 Overall Learning

Overall, this course improved the way I think about data processing at scale. It gave me a stronger foundation in performance-aware analysis and helped me understand how to work with big data more responsibly and efficiently.

Through the assignments, project, and AWS Academy courses, I learned that high-performance data processing requires a combination of good programming practices, suitable tools, efficient memory usage, cloud knowledge, and proper system design.
