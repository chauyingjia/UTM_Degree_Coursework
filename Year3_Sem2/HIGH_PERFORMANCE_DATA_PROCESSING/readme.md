# High Performance Data Processing Reflection

## Course Overview

This course focused on processing large datasets efficiently and comparing different approaches to improve performance. The work in this folder includes the academic writing paper, the big data assignment that analysed the Netflix movie ratings dataset and Projects.

I gained a better understanding of how large-scale data can be collected, processed, optimized, and evaluated using different high-performance data processing techniques. This course helped me explore both theoretical and practical aspects of data processing, including infrastructure comparison, big data handling strategies, web crawling, data cleaning, and performance benchmarking.

## Reflection

This course taught me that working with large data is not only about getting the correct result, but also about doing it efficiently. The project showed me how important it is to reduce memory usage, process data in smaller pieces, and choose the right tool for the workload.

The Netflix analysis was especially useful because it let me compare Pandas, Dask, and Polars on the same task. That comparison helped me understand the trade-offs between simplicity, speed, and scalability. It also showed me how techniques such as selecting only needed columns, chunking data, and optimising data types can make a big difference when datasets become large.
