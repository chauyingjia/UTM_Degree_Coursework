
## ☁️ Reflection on Assignment 1: AWS EC2 vs. On-Premises Servers Article

Through this assignment, I gained a better understanding of how infrastructure choices can affect high-performance data processing in large enterprises. The paper focused on comparing **AWS EC2** and **on-premises servers** based on scalability, performance, control, security, cost structure, and suitability for enterprise workloads.

### 💡 What I Gained

I learned that AWS EC2 is useful for dynamic workloads because it supports fast provisioning, elastic scaling, and flexible resource allocation. It is suitable for web-based applications that experience sudden traffic changes or unpredictable demand.

At the same time, I also learned that on-premises infrastructure is still important for large organizations that require stronger control, data sovereignty, predictable performance, and strict governance. This is especially relevant for industries such as healthcare, government, and finance, where sensitive data and system reliability are very important.

### 🖥️ Infrastructure Comparison Experience

This assignment helped me understand that infrastructure selection should not only be based on speed or scalability. Other factors such as security, compliance, internet dependency, physical control, and long-term stability must also be considered.

By comparing AWS EC2 and on-premises servers, I learned how cloud infrastructure provides flexibility, while on-premises infrastructure provides stronger ownership and control.

### 🔧 Suggested Improvements

This paper could be improved by adding more real-world case studies from companies that use hybrid cloud strategies. More cost comparison examples could also be included to show how infrastructure decisions may change based on company size, workload type, and long-term budget.

### 🌟 Overall Reflection

Overall, this assignment was meaningful because it helped me understand that high-performance data processing is not only about software tools, but also about choosing the right infrastructure. It showed me that a good infrastructure decision must balance scalability, security, control, cost, and business requirements.
