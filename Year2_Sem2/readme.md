## 💡 About This Semester

Year 2 Semester 2 continued to build on the technical foundation from the previous semester. This semester included programming, data analytics, operating systems, data mining, and entrepreneurship-related subjects. It gave me more opportunities to apply technical knowledge through assignments, projects, and practical tasks. Compared to Year 2 Semester 1, this semester felt more focused on using data and technology to solve real problems.

---

## 🛠 Skills Developed

- **Data Analytics Programming** — Using programming tools to clean, analyse, and interpret data
- **Data Mining** — Discovering useful patterns, trends, and insights from datasets
- **Object-Oriented Programming** — Designing programs using classes, objects, inheritance, and encapsulation
- **Operating System Concepts** — Understanding how computer systems manage processes, memory, files, and resources
- **Communication & Presentation** — Improving academic and professional communication skills
- **Entrepreneurial Thinking** — Understanding business ideas, innovation, and value creation

## 💻 <ins><a href="https://github.com/chauyingjia/UTM_Degree_Coursework/tree/main/Year2_Sem2/DATA%20ANALYTICS%20PROGRAMMING">Data Analytics Programming</a></ins>

### Course Overview

Data Analytics Programming introduced the use of programming for data analysis tasks. The course focused on handling datasets, cleaning data, performing basic analysis, and presenting results in a meaningful way. It helped connect programming knowledge with real data-related problems.

### Reflection

This course was closely related to my data engineering path because it showed how programming can be used to understand data. I learned that before any useful insights can be produced, data must first be cleaned, organised, and analysed properly. This course helped me become more confident in using code to work with datasets.

## ⛏ <ins><a href="https://github.com/chauyingjia/UTM_Degree_Coursework/tree/main/Year2_Sem2/DATA_MINING">Data Mining</a></ins>

### Course Overview

Data Mining focused on discovering patterns and useful information from large datasets. The course introduced important concepts such as classification, clustering, association rules, and data preprocessing. It showed how raw data can be transformed into knowledge that supports better decision-making.

### Reflection

Data Mining was interesting because it showed the value of data beyond just storing and managing it. I learned that data can reveal hidden patterns when the correct techniques are applied. This course helped me understand how data analysis and machine learning concepts can be used to solve real-world problems.

## 🧩 <ins><a href="https://github.com/chauyingjia/UTM_Degree_Coursework/tree/main/Year2_Sem2/OBJECT-ORIENTED%20PROGRAMMING">Object-Oriented Programming</a></ins>

### Course Overview

Object-Oriented Programming focused on writing programs using objects and classes. The course covered important concepts such as encapsulation, inheritance, polymorphism, and abstraction. These concepts are important for building programs that are more organised, reusable, and easier to maintain.

### Reflection

This course helped me understand how larger programs should be structured. Instead of writing everything in one long script, I learned how to separate code into classes and objects. This made programming feel more systematic and helped me write cleaner and more maintainable code.

---

## 🖥 [Operating System](https://github.com/chauyingjia/UTM_Degree_Coursework/tree/main/Year2_Sem2/OPERATING%20SYSTEM)

### Course Overview

Operating System introduced the core concepts behind how computers manage hardware and software resources. The course covered topics such as process management, memory management, file systems, scheduling, and basic system operations. It helped explain what happens behind the scenes when programs are running.

### Reflection

Operating System was a challenging course because some concepts were more abstract compared to normal programming subjects. However, it helped me understand computers at a deeper level. Learning about processes, memory, and resource management gave me a better appreciation of how software interacts with the system.

## 🧠 [Philosophy](https://github.com/chauyingjia/UTM_Degree_Coursework/tree/main/Year2_Sem2/PHILOSOPHY)

### Course Overview

Philosophy introduced important ideas related to thinking, values, ethics, and human reasoning. The course encouraged students to reflect on different perspectives and understand how philosophical ideas can influence decision-making and society.

### Reflection

This course was different from the technical subjects, but it was still meaningful. It encouraged me to think more deeply about problems instead of only focusing on technical answers. It also helped me understand that decision-making should consider values, ethics, and different viewpoints.

## 🚀 [Technopreneurship](https://github.com/chauyingjia/UTM_Degree_Coursework/tree/main/Year2_Sem2/TECHNOPRENEURSHIP)

### Course Overview

Technopreneurship focused on the combination of technology and entrepreneurship. The course introduced how business ideas are developed, how technology can solve market problems, and how innovation can create value. It also encouraged students to think about business opportunities from a technology perspective.

### Reflection

Technopreneurship helped me see technology from a business point of view. Instead of only thinking about how to build a system, I learned to think about whether the idea solves a real problem and whether people would actually use it. This course helped me understand the importance of creativity, planning, and market awareness.

## 📝 Overall Reflection

Year 2 Semester 2 was a balanced semester that combined technical, analytical, communication, and business-related learning. The programming and data-related subjects helped strengthen my technical skills, while the non-technical subjects helped improve my communication, thinking, and problem-solving abilities.
