
# 🌐 Network Communication Reflection

## Course Overview

This course introduced the fundamental concepts of computer networks and how data is transmitted between devices. Through several lab activities, I learned about network protocols, packet analysis, routing, subnetting, ARP, switching, TCP, UDP, HTTP, DNS, and network simulation using practical tools.

The labs helped me understand network communication not only from theory, but also through hands-on activities using **Wireshark** and **Cisco Packet Tracer**.

---

## Tools Used

- Wireshark
- Cisco Packet Tracer
- Command Prompt / CLI
- Router and switch configuration
- Network simulation mode

---

## Lab Learning Experience

Through the Wireshark lab, I learned how packet sniffers capture network traffic and how protocol details can be analysed layer by layer. I explored packet information such as source and destination addresses, protocol types, HTTP messages, DNS queries, TCP/UDP details, and packet contents.

Through the TCP and UDP simulation lab, I gained a clearer understanding of how different applications generate different types of network traffic. For example, HTTP, FTP, DNS, and email traffic were generated and observed in Packet Tracer simulation mode. This helped me understand how TCP and UDP use port numbers to identify applications and support communication.

The routing protocol lab helped me understand subnetting, IP addressing, routing tables, and RIP routing configuration. I learned how routers forward packets between different networks and why proper routing configuration is needed to allow all PCs from different subnets to communicate successfully.

The ARP and switch table lab helped me understand how devices resolve IP addresses into MAC addresses and how switches learn MAC addresses dynamically. By using commands such as `show arp`, `show mac-address-table`, `ping`, and `arp -a`, I was able to observe how ARP tables and switch tables change after network traffic is generated.

---

## Reflection

This course helped me understand that network communication is a structured process involving many layers and protocols. Before taking this course, I only understood networking at a basic level, such as devices connecting to the Internet. However, after completing the labs, I could better understand what actually happens behind the scenes when devices communicate.

The practical labs were useful because they allowed me to observe real packet behaviour instead of only reading about protocols. Wireshark helped me see how packets are captured and analysed, while Packet Tracer helped me simulate how routers, switches, PCs, and servers communicate in a network.

I also learned that small configuration mistakes, such as incorrect IP addressing, missing routes, or wrong subnet masks, can prevent devices from communicating. This made me realize the importance of careful network planning, accurate configuration, and troubleshooting skills.

---

## Overall Learning

Overall, this course strengthened my understanding of network fundamentals and practical network troubleshooting. I learned how protocols such as ARP, TCP, UDP, HTTP, and DNS support communication, and how routers and switches help forward data across networks.

This course also improved my confidence in using networking tools such as Wireshark and Cisco Packet Tracer. It gave me a stronger foundation for understanding how real computer networks operate and how network problems can be analysed systematically.
