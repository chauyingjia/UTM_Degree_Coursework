
# 💻 Programming Technique II Reflection

## Course Project: Income Tax Calculator System

## Project Overview

This project was developed for the Programming Technique II course. The project focused on designing and developing an **Income Tax Calculator System** using **C++** and Object-Oriented Programming concepts.

The system was created to help users estimate their income tax based on yearly income, tax relief, tax rebate, Monthly Tax Deduction (MTD), and tax rates. The project also included an admin function that allows the tax rate to be viewed and updated when needed.

---

## Project Development

This project was completed in two main stages.

### 📌 Project 1: System Proposal and Storyboard

In the first stage, the system idea, objectives, and basic flow were planned. A storyboard was designed to show the user interface flow, including the main menu, admin login, user input pages, tax relief pages, tax rebate page, and final summary page.

This stage helped me understand the importance of planning before coding. By designing the storyboard first, the system flow became clearer and easier to implement later.

### 📌 Final Project: C++ System Implementation

In the final stage, the system was implemented using C++. The system included two main roles:

- **User**: enters income, tax relief, rebate, and MTD details to calculate income tax.
- **Admin**: verifies admin ID, displays current tax rates, and updates new income tax rates.

The system also included functions to calculate yearly income, total relief, taxable income, income tax, rebate, final tax amount, and summary output.

---

## Technologies Used

- C++
- Object-Oriented Programming (OOP)
- Header file and implementation file structure
- Console-based system interface

---

## Reflection

Through this project, I gained a better understanding of how Object-Oriented Programming can be applied in a practical system. I learned how to use classes, objects, member functions, constructors, access modifiers, and file separation to make the program more organized.

This project also helped me understand the importance of system design. Before writing the code, the use case diagram and storyboard helped define what the user and admin could do in the system. This made the development process easier because the flow of the system had already been planned.

One of the most useful parts of the project was learning how to separate the program into different files, such as `main.cpp`, `useradmin.h`, and `useradmin.cpp`. This made the code easier to read, manage, and maintain compared to writing everything in one file.

---

## Challenges Faced

One challenge faced in this project was handling the income tax calculation rules correctly. The system needed to calculate yearly income, relief, taxable income, income tax, rebate, MTD, and the final payable or return amount in the correct order.

Another challenge was designing different functions for user and admin roles. The user focused on tax calculation, while the admin focused on updating tax rates. This required clear program structure and careful function organization.

---

## Overall Learning

Overall, this project strengthened my understanding of C++ programming and Object-Oriented Programming. It helped me learn how to turn a system proposal and storyboard into a working program.

This project also showed me that programming is not only about writing code, but also about planning the system flow, organizing logic clearly, handling user input properly, and designing a system that is useful and understandable for users.
