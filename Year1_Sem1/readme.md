## 📝 Reflection

Semester 1 was a genuine reset. Coming into a Data Engineering programme without prior formal training in programming or digital systems, the learning curve in the first few weeks was steep. Programming Technique I was the course that demanded the most — not because the syntax was difficult, but because thinking algorithmically was an entirely new mental habit. Writing my first working loop felt like a small but real breakthrough.

Digital Logic and Discrete Structure turned out to be more interconnected than they first appeared. Understanding how Boolean expressions underpin circuit design, and how the same algebraic rules appear in logical proofs, gave me an early sense of how the layers in computing actually relate to each other. That cross-subject perspective became something I kept returning to in later semesters.

If I could redo this semester, I would start reading ahead on discrete mathematics earlier. The abstract notation was unfamiliar and I underestimated how long it would take to get comfortable with formal proofs. Despite that, Semester 1 gave me a solid footing — and the discipline of writing clean, structured code from the very beginning has paid off consistently in every course and project since.
