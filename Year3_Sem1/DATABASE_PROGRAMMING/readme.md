# Database Programming Reflection

## Course Overview

This course focused on how databases are used inside real applications. The work in this folder includes two major projects that show both relational and NoSQL database development, namely the smart digital attendance system and the food delivery record system.

## Reflection

This course made database concepts feel much more practical. In the SQL project, I learned how to design tables, define relationships, use constraints, and write queries that support reliable data storage and retrieval. I also saw how performance can be improved through better query design and indexing.

The NoSQL project helped me understand that not every system should be built the same way. By working with MongoDB, I learned how document design, embedding, referencing, aggregation, and CRUD operations can be used for data that changes more dynamically. Comparing the two projects showed me how the choice of database depends on the structure of the data and the needs of the application.

## Overall Learning

Overall, this course improved my understanding of how data is stored, accessed, and managed in real systems. It strengthened my database design skills and helped me connect theory with practical implementation.
