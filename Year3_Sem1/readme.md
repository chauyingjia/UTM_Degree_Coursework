## 🤖 <ins><a href="https://github.com/chauyingjia/UTM_Degree_Coursework/tree/main/Year3_Sem1/ARTIFICIAL%20INTELLIGENCE">Artificial Intelligence</a></ins>

### Course Overview

Artificial Intelligence introduced the basic concepts of how machines can be designed to perform tasks that normally require human intelligence. The course covered topics such as problem-solving, search strategies, knowledge representation, reasoning, and intelligent decision-making. It helped explain how AI systems work and how they can be applied to different real-world problems.

### Reflection

This course was interesting because it showed how computers can be used for more than just normal programming tasks. I learned that AI is not only about advanced models, but also about how problems are represented and solved logically. It helped me understand the foundation behind intelligent systems and gave me a better view of how AI connects with data and software development.

## 🗄 <ins><a href="https://github.com/chauyingjia/UTM_Degree_Coursework/tree/main/Year3_Sem1/DATABASE_PROGRAMMING">Database Programming</a></ins>

### Course Overview

Database Programming focused on using programming techniques to interact with databases. The course involved writing queries, creating database operations, handling stored procedures, and connecting databases with application logic. It helped strengthen the link between database design and actual system development.

### Reflection

This course was very useful because it made database knowledge feel more practical. Instead of only designing tables and writing SQL queries, I learned how databases are used inside real applications. It helped me understand how data is stored, retrieved, updated, and managed through programs, which is important for both software development and data engineering work.

## 🏢 <ins><a href="https://github.com/chauyingjia/UTM_Degree_Coursework/tree/main/Year3_Sem1/ENTERPRISE%20SYSTEM%20DESIGN%20AND%20MODELING">Enterprise System Design and Modeling</a></ins>

### Course Overview

Enterprise System Design and Modeling focused on analysing, designing, and modelling systems used in organisations. The course covered how enterprise systems support business processes and how system models can be used to represent requirements, workflows, and system structures. It helped connect technical system design with organisational needs.

### Reflection

This course helped me understand that system development is not only about coding. Before a system can be built, the business process, user needs, and system requirements must be understood clearly. Learning to model enterprise systems made me think more carefully about planning and design before implementation.

### Course Overview

Professional Communication Skills focused on communication in workplace and academic settings. The course covered areas such as formal communication, presentation skills, report writing, discussion, and professional interaction. ### Reflection

This course was useful because communication is important in every field, including computing. Technical skills are important, but they are not enough if ideas cannot be explained clearly. This course helped me become more aware of how to communicate professionally, especially when working in teams, presenting projects, or preparing written work.
