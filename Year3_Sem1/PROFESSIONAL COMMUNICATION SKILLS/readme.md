# Professional Communication Skills Reflection

## Course Overview

This course focused on communication in academic and professional settings. The files in this folder show the proposal outline, sample references, and presentation materials used to prepare and deliver the course project.

## Reflection

This course helped me become more aware of how important communication is in technical work. Even when the content is strong, the message still needs to be organised clearly so that other people can understand the purpose, scope, and value of the work.

Working on the proposal outline and pitching materials improved my ability to structure ideas, choose suitable wording, and present information in a more professional way. It also reminded me that communication is not only about speaking or writing well, but also about adapting the message to the audience and the situation.

## Overall Learning

Overall, this course strengthened my confidence in formal writing and presentation. It helped me see communication as a core skill that supports teamwork, project reporting, and future workplace readiness.
