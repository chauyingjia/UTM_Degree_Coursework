# Enterprise System Design and Modeling Reflection

## Course Overview

This course focused on analysing how enterprise systems are planned, modelled, and connected to business processes. The project work in this folder shows the process of studying a real problem, designing a proposed system, and preparing supporting documentation and prototypes.

## Reflection

This course taught me that system development starts with understanding the organisation, the users, and the workflow before thinking about implementation. It made me pay more attention to how requirements, process flow, and system integration affect the final solution.

The project experience helped me practise modelling a system from different angles, such as business process analysis, system structure, and interface planning. I also learned that enterprise solutions need to consider how different systems share information, because a good design should reduce duplication and make the workflow smoother for users.

## Overall Learning

Overall, this course improved the way I think about large systems. It showed me that good software design is not only about coding, but also about planning, modelling, and aligning the system with real organisational needs.
