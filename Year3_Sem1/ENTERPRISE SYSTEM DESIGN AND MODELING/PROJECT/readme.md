## 🏨 Reflection: Hostel Management System Project

Through this project, I gained a better understanding of how **Enterprise Architecture (EA)** and system integration can be applied in a university environment. The project focused on designing and developing a Hostel Management System prototype to improve residential processes such as hostel applications, room allocation, digital check-in/check-out, maintenance requests, and hostel fee monitoring.

### 💡 What I Gained

I learned how a system should be planned from both the **business perspective** and **technical perspective**. This project helped me understand how fragmented systems can cause data duplication, manual workload, and delayed information updates. By applying EA principles, I learned how different systems such as the Student Information System and Finance System can be logically connected to support smoother data flow.

I also gained practical experience in preparing system models such as **use case diagrams**, **activity diagrams**, **sequence diagrams**, **database design**, and **interface design**. Besides that, using **SAP Build Apps** helped me understand how low-code platforms can be used to quickly build system prototypes and demonstrate workflow logic.

### 🧩 System Development Experience

This project was not only about documentation. It involved analysing the current system problems, designing the proposed system architecture, planning system requirements, and developing a functional prototype. The system included student and admin workflows, such as submitting hostel applications, allocating rooms, checking payment status, submitting maintenance requests, and managing check-in/check-out processes.

### 🔧 Suggested Improvements

The system could be improved by adding **real-time integration** with actual university systems, such as student records, hostel databases, and finance systems. More advanced features could also be added, such as **automated room recommendation**, **notification alerts**, **online payment gateway integration**, and **maintenance progress tracking**.

The prototype interface could also be improved by conducting user testing with real students and hostel staff to make the system more user-friendly and practical for daily use.

### 🌟 Overall Reflection

Overall, this project was meaningful because it helped me understand how system development is connected to enterprise-level planning. I learned that a good system should not only solve one small problem, but also fit into the larger digital ecosystem of an organization. This project strengthened my knowledge in system analysis, enterprise architecture, integration design, database modelling, and prototype development.
